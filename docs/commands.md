# Команды

Все команды для игроков. Подробности — на страницах разделов (ссылки в заголовках).
Команды с пометкой <span class="nw-chip">донат</span> доступны с [привилегией](donate.md) или отдельной покупкой.

## Главное

<div class="nw-filter-group" markdown>

| Команда | Что делает |
|---|---|
| `/menu` | Главное меню сервера |
| `/help` | Справка в чате (`/help basic`, `/help pets`, `/help donate`…) |
| `/link КОД` | Привязать аккаунт ([как](start.md#2-привязка-аккаунта)) |
| `/rtp` | Разовый телепорт новичка подальше от спавна (первые 30 минут) |
| `/bonus` | 50 очков лояльности, один раз |
| `/profile [ник]` | Профиль игрока |
| `/stats` | Статистика сервера |
| `/enter` | Вход в чилл-зону |
| `/vote` | Голосование за сервер |
| `/support текст` | Позвать модерацию (`/helpop`, `/callstaff`) |
| `/discord`, `/telegram` | Ссылки на наши площадки |
| `/donate` | Витрина доната |

</div>

## [Чат](chat.md)

<div class="nw-filter-group" markdown>

| Команда | Что делает |
|---|---|
| `!текст` | Написать в глобальный чат (без `!` — локальный, 100 блоков) |
| `/msg ник текст` · `/r текст` | Личное сообщение / ответ |
| `/ignore ник` | Скрыть игрока |
| `/ad текст` | Реклама в чат |
| `/greet add текст` | Свои быстрые приветствия по клику |
| `/kiss ник` · `/slap ник` | Поцеловать / шлёпнуть |
| `/hugging on` · `/hugging off` | Разрешить или запретить обнимать себя (обнять — ++shift++ + ПКМ) |
| `/voicemsg` | Голосовые сообщения |
| `/prefix` | Свой префикс |
| `/badge` | Вариант значка ранга |
| `/skin ник` | Сменить скин |
| `/hello текст` <span class="nw-chip">донат</span> | Сообщение при входе |
| `/nick menu` <span class="nw-chip">донат</span> | Цвет ника |
| `/announce текст` <span class="nw-chip">донат</span> | Объявление на весь сервер |
| `/icon` <span class="nw-chip">донат</span> | Символ у ника |

</div>
