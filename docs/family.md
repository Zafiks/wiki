# Брак, семья, наставники

## Брак

| Команда | Что делает |
|---|---|
| `/marry ник` | Сделать предложение (ответ — в течение минуты, повтор — через 5 минут) |
| `/marry accept` · `/marry deny` | Принять / отказать |
| `/marry info` · `/marry status` | Кто ваша пара, сколько вы вместе |
| `/marry divorce` | Развод (потребуется подтверждение) |

- Перед свадьбой нужно выбрать пол персонажа: `/gender` (или `/пол`) — после привязки сервер напомнит в чате. Брак — между мужчиной и женщиной.
- О свадьбе узнает весь сервер, будет салют. :tada:
- Сменить пол, пока вы в браке, нельзя.

## Семья

Можно «усыновить» других игроков — получится семья с общим сундуком.

| Команда | Что делает |
|---|---|
| `/family` | Меню семьи (`/fam`) |
| `/family adopt ник` | Пригласить ребёнка (до 5 детей) |
| `/family accept` · `/family deny` | Ответить на приглашение в семью |
| `/family chest` | Общий семейный сундук |
| `/family kick ник` | Исключить ребёнка |
| `/family leave` | Покинуть родителей |

В меню видны годовщины: неделя, месяц, 100 дней, полгода, год.

## Наставники

Опытные игроки (хелперы) берут новичков под крыло: помогают освоиться, отвечают на вопросы.

**Новичкам:** ничего делать не нужно — в первые минуты игры наставник может предложить помощь сам.
Не стесняйтесь писать ему в личку.

**Наставникам** (`/sen` или `/mentor`):

| Команда | Что делает |
|---|---|
| `/sen menu` | Свой профиль и подопечные |
| `/sen accept ник` · `/sen decline ник` | Принять / отклонить предложенного новичка |
| `/sen join ник` | Взять свободного новичка вручную |
| `/sen tp ник` | Телепорт к подопечному |
| `/sen spawn` | Точка сбора наставников |
