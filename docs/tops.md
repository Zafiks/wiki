# Топы и награды

## Профиль и статистика

| Команда | Что показывает |
|---|---|
| `/profile [ник]` | Профиль: награды, ордены, статистика. Клик по нику в чате открывает его же |
| `/stats` | Статистика сервера и игроков |
| `/g top` | Рейтинг [объединений](groups.md) |
| `/war top` | Рейтинг объединений по [войнам](wars.md) |
