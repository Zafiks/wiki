# Объединения

Объединение (клан) — своя команда с тегом, званиями, чатом, заданиями и рейтингом.
Меню — `/g` (или `/group`, `/union`).

## Создать и собрать людей

| Команда | Что делает |
|---|---|
| `/g create ТЕГ Название` | Создать объединение — 300 очков лояльности |
| `/g invite ник` | Пригласить игрока |
| `/g accept ТЕГ` | Принять приглашение |
| `/g recruit текст` | Открыть набор с объявлением (видно в каталоге). `/g recruit off` — закрыть |
| `/g catalog` | Каталог всех объединений — можно найти, куда вступить |
| `/g leave ТЕГ` | Выйти |

## Управление

| Команда | Что делает |
|---|---|
| `/g` · `/g menu ТЕГ` | Меню объединения |
| `/g chat текст` | Чат только для своих |
| `/g title ник звание` | Выдать звание участнику |
| `/g promote ник` · `/g demote ник` | Повысить / понизить |
| `/g kick ник` | Исключить |
| `/g setleader ник` | Передать лидерство |
| `/g rename Название` | Сменить название |
| `/g disband` | Распустить |
| `/g info` | Информация |
| `/g tasks` | Задания объединения |
| `/g top` · `/g rating` | Рейтинг объединений |

Можно состоять в нескольких объединениях — одно из них «активное», его тег показывается у ника.

## Очки рейтинга

| За что | Очков |
|---|---|
| Новичок вступил в объединение | +50 |
| Час игры участника | +1 |
| Выполненное задание (`/g tasks`: добыть, убить, вырастить…) | +20…50 |
| Победа в [войне](wars.md) | +100 |

## В сезоне

В [сезоне](season.md) участникам объединения звёзд на 10% больше, за каждое выполненное недельное задание
(`/g tasks`) каждый получает +40★, а звёзды участников идут в лигу кланов — три лучших клана получают награды.

## Королевство

У объединения может быть своё королевство — участок земли вокруг флага, который виден на [карте сервера](https://map.nightworld.ovh).

1. Лидер или офицер берёт флаг: `/g флаг` или кнопка «Королевство» в меню `/g`.
2. Ставит его в обычном мире **дальше 400 блоков от спавна** — вся земля королевства должна быть за этой границей (на карте она обведена красным кругом).
3. Вокруг флага появляется квадрат земли цвета объединения. Сначала 49×49, дальше он растёт с [очками рейтинга](#очки-рейтинга): +1 блок во все стороны за каждые 10 очков, до 193×193.

Между королевствами всегда остаётся не меньше 16 блоков. Старшее королевство растёт первым, но младшему всегда остаётся хотя бы 49×49.

Земля королевства **не защищена** — строить и ломать на ней может любой, как и везде. Неуязвим только сам флаг: его нельзя сломать, взорвать или сдвинуть.

| Команда | Что делает |
|---|---|
| `/g флаг` | Получить флаг (лидер или офицер) |
| `/g королевство` | Где флаг, размер земли, сколько очков до роста |
| `/g королевство снять` | Снять флаг — он вернётся в инвентарь. Переставлять можно раз в 3 дня |
| `/g королевство список` | Все королевства сервера |

Если объединение распалось или ушло в архив, его королевство исчезает.

## Чтобы объединение не ушло в архив

- В нём должно быть **не меньше 3 участников**.
- Кто-то из участников должен заходить на сервер хотя бы раз в **7 дней**.

Новому объединению даётся 14 дней, чтобы набрать людей. Лидер получает предупреждение заранее.
В архиве у участников пропадает префикс. Участники, которые не заходили **21 день**, исключаются автоматически (лидера это не касается).

Состоять можно только в **одном** объединении: чтобы перейти в другое, сначала выйдите из своего (`/g leave`).
