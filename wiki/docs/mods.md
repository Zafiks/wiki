# Моды

Играть можно и на чистом клиенте. Но сервер поддерживает несколько модов, с которыми интереснее.
Все они — для **Fabric** (кроме тех, где указано иное) под версию **1.21.11**. Ставьте с Modrinth.

| Мод | Зачем |
|---|---|
| [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat) | Голосовой чат по близости, [голосовые сообщения](chat.md#голосовые-сообщения), музыка с [пластинок](creativity.md#своя-музыка-на-пластинке), голоса квестовых NPC. **Самый полезный.** |
| [Emotecraft](https://modrinth.com/mod/emotecraft) | Эмоции и танцы — их видят другие игроки с модом. |
| <span id="rprenames"></span>[RPRenames](https://modrinth.com/mod/rprenames) | Показывает в наковальне все [названия из ресурс-пака](renames.md) — не нужно вводить вручную. |
| [PatPat](https://modrinth.com/mod/patpat) | Гладить игроков и мобов. |
| [Female Gender Mod](https://modrinth.com/mod/female-gender) | Женская модель персонажа. |
| [Dream Displays](https://modrinth.com/mods?q=dream+displays) | Видео на экранах в мире. Без мода экраны просто не видно. |

!!! info "Без мода — тоже можно"
    Ни один мод не обязателен. Голосовые сообщения, пластинки и голоса NPC без Simple Voice Chat вы просто не услышите.

!!! danger "Читы"
    На сервере работает античит. X-ray, киллауры, автокликеры, флай и любые клиенты с преимуществом — бан.
    Миникарты без показа мобов/руд и «косметические» моды — можно. Сомневаетесь — спросите в Discord.
