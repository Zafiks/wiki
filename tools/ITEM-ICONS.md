# Иконки каталогов

Запускать из каталога `wiki`, последовательно, без публикации:

```sh
.venv/bin/python -I tools/gen_item_icons.py ../resourcepack/nightworld-rp-v25.zip
.venv/bin/python -I tools/gen_renames.py ../resourcepack/nightworld-rp-v25.zip
.venv/bin/python -I tools/gen_wardrobe_items.py ../resourcepack/nightworld-rp-v25.zip
.venv/bin/python -I -m mkdocs build --strict
```

Путь к паку — аргумент. Для другого каталога VCore у генераторов иконок
и гардероба есть `--cosmetics`, у генератора гардероба также `--packs`.
Ванильные родители и текстуры читаются из уже установленного клиента
1.21.11 по пути в `resourcepack/modelpreview.py`. Скрипты ничего не скачивают,
не распаковывают архив целиком и не записывают в пак или VCore.

Генерация идёт одним потоком. Кэши моделей и декодированных текстур
освобождаются после каждого предмета; грани одной модели разделяют текстуру.
Адресное пространство процесса ограничено 768 МиБ (более строгий внешний
лимит сохраняется). В конце выводится измеренный пик оперативной памяти.

`item-icons.json` содержит SHA-1 → путь к WebP. Ключ учитывает всю цепочку
модели, байты текстур, метаданные анимации и исходные цвета. Запись картинок
и индекса атомарная; индекс сохраняется также каждые 100 уникальных иконок.
После прерванного запуска готовые корректные WebP используются повторно.
Удаляются только неиспользуемые файлы с именами из 12 шестнадцатеричных цифр.
Набор иконок соответствует строкам обеих страниц после объединения семейств.

Ошибки отдельных предметов выводятся в консоль и `item-icons-errors.txt`.
В таблице такой предмет остаётся с прочерком. Ванильный вид также получает
прочерк. В репозитории вики сохраняются только иконки 64×64 и их индекс,
без исходных моделей и текстур.

Проверки на небольших временных ресурс-паках, без игры и загрузок:

```sh
.venv/bin/python -I tools/test_item_icons.py
```

Они проверяют выбор именованного варианта и основного вида, влияние родителя,
текстуры и окраски на ключ, первый кадр анимации, слои, прозрачность 3D,
пропуск ванильных и повреждённых моделей, повторное использование кэша
и удаление устаревших иконок.
