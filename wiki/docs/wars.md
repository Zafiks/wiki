# Войны объединений

Лидер вызывает другое объединение, стороны договариваются о ставках, и не раньше чем через сутки
идёт **2-часовой бой в Энде**. Больше убийств соперников — победа и все ставки.

## Команды

| Команда | Что делает |
|---|---|
| `/war` | Меню войн вашего объединения |
| `/war top` | Рейтинг объединений по войнам |
| `/war challenge ТЕГ` | Бросить вызов (только лидер) |
| `/war accept` · `/war decline` | Ответить на вызов |
| `/war terms` | Переговоры: рейтинг, косметика, ресурсы, состав, время |
| `/war info` | Ход войны, счёт и составы |
| `/war invite ник` | Позвать в бой новичка без объединения |
| `/war join` · `/war deny` | Ответить на такое приглашение |
| `/war claim` | Забрать выигранные предметы, которые не влезли в инвентарь |

## Правила войны

| | |
|---|---|
| **Кто может** | Объединения от 3 участников, которым больше 3 дней |
| **Составы** | Фиксируются при подтверждении; разница — не больше 2 игроков |
| **Ставки** | Рейтинг, трофейная косметика и ресурсы уходят в залог |
| **Счёт** | Только убийства соперников в Энде. Ничья — ставки возвращаются |
| **Бой** | Посторонние не могут бить участников. Ушли из Энда или вышли с сервера после удара — засчитывается смерть |
| **Перерыв** | Те же два объединения — не чаще раза в 3 дня |

!!! warning "В Энде нельзя летать"
    Элитры, полёт и летающие маунты в Энде отключены — воюют на земле.
